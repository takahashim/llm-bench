# Markdown 1枚からEPUBとPDFを作るCheepubを公開した

Markdownの文書を用意し、必要ならメタデータや章の区切りを追加して実行するとEPUBが出力される。オプションでPDFも出力できる。

```bash
cheepub -o output epub.md
# PDFを出す場合
cheepub -t "タイトル" -a "著者名" -p "識別子" -d "2018-12-26" -u "最終更新日時" -s "ページ送り方向" --pdf epub.md
```

(コード)

## Cheepubとは

コマンドラインから使えるでんでんコンバーターのようなものを目指している。Markdownの文書を簡単にEPUB化したい人向け。

## 特徴

*   設定はJekyllのように文書冒頭のYAMLで記述する。
*   文書本体と設定を分離しない。1つのファイルで完結する形にする。
*   Re:VIEWにある便利な仕掛けはかなり落としている。

## 設定

| 項目名     | 説明                               |
| :--------- | :--------------------------------- |
| タイトル     | 出力文書のタイトル                   |
| 著者       | 出力文書の著者                       |
| 識別子     | 出力文書の一意な識別子               |
| 出版日     | 出力日                               |
| 最終更新日時 | 更新日時                             |
| ページ送り方向 | `top` (上)、`bottom` (下)          |

## 表紙

タイトルページは出せるが、EPUBの表紙の見栄えは適当なので少し手を入れたい。表紙画像には対応していない。

## 奥付

奥付も出力できる。以下の項目を指定する。

| 項目名     | 説明                               |
| :--------- | :--------------------------------- |
| タイトル     | 出力文書のタイトル                   |
| 著者       | 出力文書の著者                       |
| 出版日     | 出力日                               |
| 発行者     |                                |
| ISBN        |                                |
| 印刷者     |                                |
| 製本者     |                                |
| 装丁者     |                                |
| カバーイラスト |                                |

## Markdown記法

kramdownを使ってMarkdownを解析する。ルビ、縦中横、脚注の記法に対応している（でんでんマークダウンに寄せた）。表は左右両端に縦棒がある形式のみ対応しており、それ以外の形式では表として認識されないため、記述が衝突してしまう。

*   ルビ
    ```markdown
    \[[ruby]](ルビー)
    ```
    (コード)

*   縦中横
    ```markdown
    \[縦中横]文字列
    ```
    (コード)

*   脚注
    ```markdown
    [1](#footnote_1)文字列

    <div id="footnote_1" class="footnote">
      脚注の内容
    </div>
    ```
    (コード)

## PDF出力

PDFを生成する際にはLaTeXを使う。縦書きや2段組はそのまま対応できる。

*   縦中横
    ```markdown
    \[縦中横]文字列
    ```
    (コード)

*   2段組
    ```markdown
    ::::
    ```
    (コード)
## Re:VIEWとの違い

番号付けや目次などがどうしても必要な場合はRe:VIEWを使う方が良い。

## でんでんコンバーターとの違い

でんでんマークダウンをそのまま使いたい場合にはでんでんコンバーターの方がおすすめである。互換性を高めるpull requestを受け付けるかもしれないが、そこまでは対応しないかもしれない。

## ライブラリ

*   kramdown: Markdownの解析
*   gepub: EPUBの生成
*   rb\_latex: LaTeX経由でのPDF生成 (upLaTeXまたはLuaLaTeX)

## Rubyバージョン

Ruby 2.5系を想定しているが、2.3あたりでも動くかもしれない。PDF出力にはupLaTeXかLuaLaTeXが必要で、TeX Liveに入っているものを使うのがおすすめである。

## 改行コード

改ページはイコール記号を3つ以上並べた行（前後に空行）またはハイフン6つ以上の行とする。3〜5個なら通常の区切り線として残るので、書き分けられる。この規則は後で変更するかもしれない。

## 拡張

*   kramdown拡張: 段落にclass属性を付ける
    ```markdown
    .my-class { ... }
    ```
    (コード)
*   LaTeX拡張: 右寄せ
    ```latex
    \begin{center}
      ...
    \end{center}
    ```
    (コード)

## その他

*   縦中横で使える文字をASCIIの範囲に制限しているが、この制限は不要だったかもしれない。
*   rb\_latexを使うので、Ruby 1.9では動かない。2018年なのだからもう少し新しいRubyを使ってほしいところ。

# RubyNextでES6風のHash省略記法を動かす

## RubyNextでES6風のHash省略記法を動かす

RubyNextはEvil MartiansのVladimir Dementyev氏が手がけているRubyのトランスパイラです。gemとしてインストールしてGemfileからbundle installで使うこともできます。

https://github.com/vdemidov/ruby-next

## RubyNextのできること

RubyNextは以下の3通りのことができます。

* 古い処理系で新しいバージョン向けのコードを動かす
* まだ出ていないバージョン向けのもの（Edge features）を動かす
* 提案されただけで取り込まれていないもの（Proposed features）を動かす

このうちRubyNextが提案されただけで取り込まれていない機能を使うには、専用のファイルをrequireすることで利用できます。RubyNext 0.10.0時点ではメソッド参照の演算子とHashの省略記法の2つが使えます。今回は後者を使ってみます。

## Hash省略記法について

JavaScript側で見慣れたキーだけを並べる書き方を、Rubyでも書けたら便利だと考える人は当然いるでしょう。ES6(ES2015)で入った値の省略記法に相当するものをRubyにも、という提案は過去に何度も出されており、#11105や#15236、値だけを省く形の#14579も、いずれも受け入れられないままになっています。

https://github.com/ruby/ruby/issues/11105
https://github.com/ruby/ruby/issues/15236
https://github.com/ruby/ruby/issues/14579

## RubyNextの利用方法

RubyNextはトランスパイラなので、提案されたものを同梱することができます。提案された機能は正式に採用される前に多くの人が気軽に試せる場を用意するためで、JavaScript界のやり方を手本にしているということです。

RubyNextが変換した結果を別ファイルとして書き出すこともできますし、requireとrequire_relativeを入れ替えて実行時にライブラリを書き換えながら動かすこともできます。

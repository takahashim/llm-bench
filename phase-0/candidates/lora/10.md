# Markdown 1枚からEPUBとPDFを作るCheepubを公開した

## Cheepubの紹介

Markdownで手軽に電子書籍やPDFを作りたい人向けです。

### 概要

Cheepubは1枚のMarkdownに設定ごと書き込み、そこからEPUBとPDFを出すところだけに絞った道具です。番号付けや完全な互換性まで求める人には向かないと最初から割り切っています。

### 特徴

*   **簡潔さ**: 設定ファイルを分割したり、本文を分割したりしません。
*   **手軽さ**: Jekyllのように、設定はMarkdownの先頭にYAMLで書くだけです。
*   **Ruby**: Rubyのgemとして配布します。Ruby 2.5系が推奨ですが、2.3あたりでも動きそうです。

### インストール

CheepubはRubyGems経由でインストールできます。

```bash
gem install cheepub
```

### 使用例

Markdownの文書を用意し、必要ならメタデータと章の区切り（`---`）を足して、コマンドを叩くとEPUBが生成されます。オプションに `-p` を付けるとPDFが出力されます。

```bash
cheepub mydoc.md
```

### 設定

CheepupはJekyllのようにMarkdownの先頭にYAMLで設定を書きます。

```markdown
---
title: こういうタイトル
author: 著者名
# 出版日: 2018-11-01
---

ここに本文...
```

設定できる項目は以下の通りです。

*   `title`: タイトル (必須)
*   `author`: 著者 (必須)
*   `identifier`: 識別子 (UUIDを自動生成します。省略時はUUIDを自動生成します)
*   `pubdate`: 出版日 (現在日時を使用します。PDFでは使われません)
*   `modified`: 最終更新日時 (現在日時を使用し、PDFでは使われません)
*   `direction`: ページの送り方向 ("rtl" または "ltr"。デフォルトは "ltr")
*   `toc`: 目次の有無 ("true" または "false"。デフォルトは "true")

### 付録

CheepubはRe:VIEWにある便利な仕掛けをかなり落としています。

*   章や節番号は自動的に振られません。
*   図表の番号も自動では振られません。
*   図表にはキャプションがありません。
*   目次は今のところ出ません。

番号付けや目次のような仕掛けがどうしても必要なら、Re:VIEWを選ぶ方が良いでしょう。

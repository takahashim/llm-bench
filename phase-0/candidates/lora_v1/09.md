# DHHの新しいデプロイツールMRSKを試してみた

# 題
DHHの新しいデプロイツールMRSKを試してみた
## はじめに

DHHが2023年1月に作り始めたコンテナ向けのCapistranoとでも言うようなデプロイツール。いかにもDHHらしい。

## 背景

37Signalsはクラウドから引き揚げている。負荷が安定しているなら自前の機材の方が安く済むという判断らしい。とはいえ自前の機材には運用の基盤が要る。以前使っていたKubernetesを自分たちで回すのも重いので、簡単なものを自作した方が早いという発想から生まれた。

## MRSK

MRSKは37Signalsがクラウドから引き揚げる過程で生まれた道具らしい。クラウドネイティブな今の目線からするとむしろ懐かしい感じがするが、世の中の需要としては、クラウドから撤退するより、実験や学習、個人の開発のために安くて控えめなサーバの上で動かしたいという方が大きそう。そこでコンテナを使おうとするとAWSなどで費用をかけて組むか、面倒を隠してくれる便利なサービスに乗るかになり、あれが無いこれが高いという話になりがちだった。サーバまわりに慣れた人が格安のコンテナ環境を手軽に回す道具として期待できる。

## MRSKを使ってみた

試すのに必要なのはsshで入れるLinuxサーバ（推奨されるのはUbuntuかDebian）、イメージの置き場になるDocker Hubなどのアカウント、そしてアプリ用のDockerfile。サーバはAWSでもAzureでもDigitalOceanでもLinodeでもベアメタルでもよく、国内ではWebARENA Indigoが月額349円で最も安そうで、そこでも動いた。

## まとめ

MRSKはまだ完成度が低い、よく言えば伸び代だけがある状態なので、それを面白がれる人なら手を出してみるとよさそう。筆者自身もcapistranoで回しているアプリをこれに移してみようかと思った。

Herokuの有料化が騒ぎになる前にこれが仕上がっていたら、選べる手が増えてよかったのに、という感想を持った。クラウドの費用に不満がない人には要らない道具だが、出費を抑えて自前のサーバで色々やりたい人には実用になりそうで面白い。

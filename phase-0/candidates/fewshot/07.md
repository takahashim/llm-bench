# RubyNextでES6風のHash省略記法を動かす

## RubyNextでES6風のHash省略記法を動かす

RubyNextはEvil MartiansのVladimir Dementyevが手がけているRubyのトランスパイラです。gemとしてインストールできるため、Gemfileに書いてbundle installすることでも利用できます。

https://github.com/vdemartino/ruby-next

なお、RubyNextができることは3通りあります。古い処理系で新しいバージョン向けのコードを動かす、まだ出ていないバージョン向けもの（Edge features）を動かす、提案されただけで取り込まれていないもの（Proposed features）を動かします。

RubyNextは提案段階の機能を同梱しているため、正式に採り入れる前に多くの人が気軽に試せる場を用意するのに便利です。JavaScript界がやっているように、この方式をRuby本体の開発でも取り入れられないでしょうか？興味がある人は試してみてください。

提案された機能は専用のファイルをrequireすると有効になります。今回使ったのはruby-next-0.10.0のHash省略記法です。https://github.com/vdemartino/ruby-next/blob/master/lib/ruby-next/stdlib/hash.rb

なお、今回のように変換した結果を別ファイルとして書き出すこともできますが、requireとrequire_relativeを入れ替えて実行時にライブラリを書き換えながら動かすことも可能です。

https://github.com/vdemartino/ruby-next/blob/master/lib/ruby-next/stdlib/hash.rb

上記は冒頭のrequireでruby-next-0.10.0を呼び込んでいます。なお、RubyNextを使うとこのようなES6(ES2015)のHash省略記法が使えるようになります。

[コード]

実行すると以下のように動きます。

$ ruby hash.rb
hello world
{:a=>1, :b=>2}

正体は冒頭に置いたrequireの行で、RubyNextを呼び込んでいます。なお、この手はライブラリ側に書かないと通らず、読み込む側のスクリプトに直接この記法を書くことはできません。

https://github.com/vdemartino/ruby-next/blob/master/lib/ruby-next/stdlib/hash.rb

requireの入れ替えはどこにでも効くわけではなく、既定の対象はlib、app、specのような決まった名前のものだけで、それ以外に広げるには監視対象ディレクトリの設定が必要です。

https://github.com/vdemartino/ruby-next/blob/master/lib/ruby-next/stdlib/hash.rb

なお、この機能自体は#11105や#15236、値だけを省く形の#14579もいずれも却下された提案ですが、JavaScript側で見慣れたキーだけを並べる書き方をRubyでもできたら便利だと考える人は当然いるはずです。

https://github.com/vdemartino/ruby-next/blob/master/lib/ruby-next/stdlib/hash.rb

なお、この機能はruby-next-0.10.0の時点ではメソッド参照の演算子とHash省略記法のみが使えます。

この機能を使うには、変換を構文解析とコンパイルの前に差し込む必要があります。裏を返すと、この手はライブラリ側に書かないと通らず、読み込む側のスクリプトに直接この記法を書くことはできません。

なお、今回のように変換した結果を別ファイルとして書き出すこともできますが、requireとrequire_relativeを入れ替えて実行時にライブラリを書き換えながら動かすことも可能です。
